How LDA Maximizes Class Separability in AI

Linear Discriminant Analysis (LDA) is a fundamental technique in artificial intelligence used for supervised dimensionality reduction and classification. This article provides a comprehensive overview of how LDA reduces the number of features in a dataset by finding a new feature space that maximizes class separability. Unlike unsupervised techniques that ignore data labels, LDA explicitly uses class information to project data onto a lower-dimensional space. It achieves this optimal projection by mathematically maximizing the between-class variance relative to the within-class variance, ensuring that different categories are pushed as far apart as possible while individual data points within the same category are clustered tightly together.

To understand how LDA functions, it is necessary to contrasted it with Principal Component Analysis (PCA). While PCA seeks to find the axes with the maximum overall variance in an entire dataset regardless of class labels, LDA focuses solely on separability among known categories. In high-dimensional AI datasets, features often overlap, making classification difficult and computationally expensive. LDA solves this by projecting the multi-dimensional data onto a line or hyperplane where the specific groupings are most distinct.

The mechanism relies on two main statistical metrics: within-class variance and between-class variance.

Within-class variance measures the spread or scatter of data points inside a single category. In mathematical terms, this is represented by the within-class scatter matrix (\(S_W\)). For every class in the dataset, LDA calculates the distance of each data point from the mean (centroid) of that specific class. It then sums these squared distances across all classes. The goal of LDA regarding this metric is minimization; a smaller within-class variance means that the data points of a specific category are densely packed together, reducing the likelihood of overlap with other categories.

Between-class variance measures how far apart the different categories are from one another. This is represented by the between-class scatter matrix (\(S_B\)). For a simple two-class problem, this is calculated by finding the distance between the mean of the first class and the mean of the second class. For multiple classes, LDA calculates the distance between the mean of each individual class and the overall global mean of the entire dataset, weighted by the number of samples in each class. The goal here is maximization; a larger between-class variance ensures that the centers of different categories are separated by as much space as possible.

To achieve supervised dimensionality reduction, LDA must optimize both of these metrics simultaneously. Simply maximizing the distance between class means is insufficient if the data within those classes is heavily scattered, as the edges of the classes will still overlap. Therefore, LDA combines these two concepts using Fisher’s Criterion.

Fisher’s Criterion defines the objective function as a ratio: the between-class scatter divided by the within-class scatter. In linear algebra terms, LDA looks for a projection vector (\(w\)) that maximizes the following ratio:

\[J(w) = \frac{w^T S_B w}{w^T S_W w}\]

To find the maximum of this ratio, calculus is applied. By taking the derivative of the function with respect to the projection vector \(w\) and setting it to zero, the optimization problem transforms into a generalized eigenvalue problem:

\[S_W^{-1} S_B w = \lambda w\]

In this equation, \(w\) represents the eigenvectors and \(\lambda\) represents the eigenvalues. The eigenvectors define the new axes (the directions of the new feature space), and the eigenvalues represent the magnitude of class separability along those specific axes.

To complete the dimensionality reduction, the AI algorithm calculates the eigenvectors and eigenvalues for the scatter matrices. It then sorts the eigenvectors in descending order based on their corresponding eigenvalues. The eigenvector with the largest eigenvalue offers the highest ratio of between-class variance to within-class variance. By selecting the top \(k\) eigenvectors, the algorithm constructs a projection matrix. Finally, the original high-dimensional data is multiplied by this matrix, successfully compressing the data into a \(k\)-dimensional space where the classes are maximally separated and ready for efficient classification.
