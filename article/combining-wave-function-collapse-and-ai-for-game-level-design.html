Combining Wave Function Collapse and AI for Game Level Design

Procedural content generation (PCG) in modern video game development increasingly relies on combining the Wave Function Collapse (WFC) algorithm with artificial intelligence to automatically build complex, playable levels. This article provides an overview of how WFC handles local structural coherence through constraint solving, how AI introduces high-level design awareness, and how the integration of these two technologies guarantees that generated environments are not only visually seamless but also navigable, balanced, and fully playable.

Understanding Wave Function Collapse

Wave Function Collapse is a constraint-solving algorithm inspired by quantum mechanics that generates patterns or 3D structures based on a small input sample. In level design, a grid is initialized in a state of "superposition," meaning every tile on the grid could potentially contain any level module (such as a corner wall, an open floor, or a doorway).

The algorithm operates through the following steps:

  1. It analyzes an input example or a set of adjacency rules to understand which tiles are allowed to sit next to each other.
  2. It picks the grid cell with the lowest "entropy" (the fewest remaining possible tile options) and collapses it into a single, definite state.
  3. It propagates the consequences of this choice to neighboring cells, eliminating incompatible options across the grid.
  4. It repeats this cycle until the entire grid is resolved.

The Playability Problem with Pure WFC

While WFC excels at making sure local details match—such as ensuring pipes connect correctly and walls do not abruptly end—it lacks global awareness. Because WFC only cares about immediate neighbor constraints, it frequently generates unplayable levels. Common issues include:

  • Unreachable areas blocked off by continuous walls.
  • Missing paths between the level entrance and exit.
  • Poor pacing, such as clustering all enemy spawn points in one corner while leaving the rest of the map empty.

How AI Bridges the Gap

Artificial intelligence, particularly machine learning (ML) and reinforcement learning (RL), excels at understanding high-level patterns, pathfinding, and strategic optimization. By combining AI with WFC, developers can force the constraint solver to adhere to macro-level game design rules.

1. Learning Adjacency Rules via Machine Learning

In complex 3D games, manually defining every tile adjacency rule for WFC is time-consuming. Machine learning models, such as Convolutional Neural Networks (CNNs), can scan existing human-made levels to automatically extract probabilities and adjacency constraints. The AI feeds these learned rules directly into the WFC algorithm, ensuring the generated output mimics the style of a human designer.

2. AI-Guided Heuristic Collapse

In standard WFC, when multiple tiles have the same lowest entropy, the algorithm picks one at random. When integrated with AI, a neural network or a Reinforcement Learning agent replaces this random choice. The AI evaluates the current state of the board and chooses the tile most likely to lead to a functional, playable level, steering the generation toward specific design goals like creating a boss arena or a chokepoint.

3. Macro-Layout Generation

Developers often use a top-down approach where an AI model (like a Generative Adversarial Network or a Markov Chain) first sketches a low-resolution layout of the level. This sketch defines the critical path, ensuring the player can move from start to finish, and places key objectives. WFC is then executed within the boundaries of this AI-generated skeleton to fill in the high-resolution geometry, textures, and props without breaking the pre-established path.

4. Automated Playtesting and Iterative Repair

Once WFC completes a level, AI navigation agents (using algorithms like A* or trained RL policies) immediately simulate playthroughs of the generated space. These agents test if jumps are possible, if the exit is reachable, and if combat encounters are survivable.

If an AI agent gets stuck, it flags the specific coordinates of the bottleneck. Instead of discarding the entire level, the system resets the WFC state in just that localized area and re-runs the collapse with stricter constraints until the AI agent successfully navigates the space.
